# Rinarda Lahu — Portfolio

Personal portfolio built with Next.js, TypeScript and Tailwind CSS.

- Edit all content in `src/data/profile.ts` (projects, skills, links).
- Add project screenshots to `public/projects/` and set `image` on the project.
- Replace `public/Rinarda_Lahu_CV.pdf` to update the downloadable CV.

```bash
npm install
npm run dev
```
